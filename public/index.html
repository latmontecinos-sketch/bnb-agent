How it works

  1. Read the pool and balances

    The agent reads its wallet and the PancakeSwap V2 testnet WBNB / USDT pool to get the current price and portfolio mix. Native BNB and WBNB count as one side.

  2. Compute drift against the target

    It compares the BNB-side weight with the target (50/50 by default). Inside the 1% threshold it does nothing; past it, it sizes the swap that brings the mix back.

  3. Swap with guardrails

    It swaps on PancakeSwap with a 1% slippage cap and at most 0.02 BNB per transaction. A daily cron runs the check; nothing else triggers a trade.

  • Target 50 / 50
  • Drift threshold 1%
  • Slippage 1%
  • Max per tx 0.02 BNB
  • Schedule daily

Owner-only execution. Only the agent's owner can trigger a real swap. Anyone else who calls the agent over A2A gets a dry-run plan: what it would do, without sending a transaction.
